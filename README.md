# כזוהר הרקיע · עולמות יחד

אתר הגיוס לקומפלקס הרוחני-קהילתי בנתיבות, בעיצוב חדש בשם **„אבן ושחר”**: אבן ירושלמית בזריחה בנגב.

- **הטקסטים** הועתקו מהאתר המקורי (`main`) ללא שינוי בעובדות, במספרים או בהטבות.
- **כל השאר חדש**: עיצוב, פלטה, גופנים (Bellefair + IBM Plex Sans Hebrew), לוגו, אייקונים, תמונות, קוד וקוד QR.
- **חוויית תלת-ממד**: בראש העמוד אבק מדבר מתגבש בגלילה ל„בניין של אור”, ובסוף מתמוסס לתמונת ההמחשה. במקטע השותפות, בחירת רמה „מדליקה” חלק מהבניין.
  כל התוכן, המחירים והטפסים נמצאים ב-HTML. התלת-ממד נטען רק אחרי שהגולש מתחיל לגלול או להזיז את העכבר, יורד באיכות אם הקצב נמוך, נעצר כשהוא מחוץ למסך, ומוחלף בתמונה קבועה כשמוגדרים „הפחתת תנועה” או „חיסכון בנתונים”.

## הרצה מקומית

אין שלב בנייה. מספיק שרת סטטי:

```bash
python3 -m http.server 8000
# ואז לפתוח http://localhost:8000
```

## מבנה

| נתיב | תוכן |
|---|---|
| `index.html` | העמוד כולו (RTL, עברית) |
| `assets/css/site.css` | עיצוב, ערכת יום ו„לילה במדבר” |
| `assets/js/main.js` | ממשק: תפריט, חלונית תרומה, העתקה, ערכת צבעים, גלילה |
| `assets/js/building.js`, `hero-scene.js`, `ignite-scene.js` | סצנות התלת-ממד (three.js) |
| `assets/vendor/` | three.js r180, GSAP + ScrollTrigger, Lenis (קבצים סטטיים) |
| `assets/fonts/`, `assets/img/` | גופנים ותמונות (AVIF/WebP ב-3 רוחבים) |
| `tools/build-assets.cjs` | יצירה מחדש של הגופנים, הספריות, התמונות וקוד ה-QR |
| `backup-legacy/` | גיבוי האתר הישן (לא לשנות) |

## פריטים פתוחים לעמותה

1. **הדמיה אדריכלית אמיתית**: כל התמונות נוצרו בבינה מלאכותית ומסומנות „המחשה”. מומלץ להחליף את תמונות הבניין (`building-dawn`, `building-night`) בהדמיה של האדריכל, ואת שאר התמונות בצילומים אמיתיים כשיהיו.
2. **תמונת הרב**: שם הרב מופיע בטקסט בלבד, בלי דיוקן. אם רוצים תמונה, יש לספק צילום מאושר.
3. **נדרים פלוס**: הכפתור פותח את דף התרומה הכללי (`mosad=5776132`) בלשונית חדשה. יש לברר עם נדרים פלוס אם אפשר להעביר בקישור את הסכום ואת מספר התשלומים, ולהוסיף זאת במקום שמסומן `TODO(org)` ב-`index.html`.
4. **ניסוח המס**: הסכום „לאחר החזר מס של עד 35%” הוא הערכה (מחיר × 0.65) עם ההערה „תלוי בחבות המס האישית”. הניסוח טעון אישור של רו״ח או יועץ משפטי.
5. **שדה ההקדשה** בחלונית התרומה הוא תצוגה מקדימה בלבד ואינו נשלח לשום מקום.
